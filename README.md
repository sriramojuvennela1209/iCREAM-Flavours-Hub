# 🍦 iCREAM – Flavours Hub

A responsive and interactive ice cream and dessert ordering web application built using **HTML, CSS, and JavaScript**.

## 📌 Project Overview

**iCREAM – Flavours Hub** is a web-based food ordering application that allows users to browse different ice creams, juices, cakes, waffles, pancakes, brownies, milkshakes, and desserts.

The application provides a simple ordering experience with user login, product categories, shopping cart, checkout, payment method selection, multilingual support, and order history.

## ✨ Features

* 🔐 User Login
* 🍦 Ice Cream & Dessert Menu
* 🧃 Fresh Juices
* 🎂 Cakes
* 🧇 Waffles
* 🥞 Pancakes
* 🍫 Brownies
* 🥤 Milkshakes
* 🍧 Desserts
* 🔎 Category-based product filtering
* 🛒 Shopping cart with quantity controls
* 💰 Automatic total price calculation
* 💳 Multiple payment method selection
* 🔊 Payment sound and voice notification
* 📦 Order placement and order history
* 🌐 Multilingual support:

  * English
  * Telugu
  * Hindi
* 💾 Browser `localStorage` for session, cart, and order data
* 📱 Responsive user interface

## 🛠️ Technologies Used

* **HTML5** – Structure of the web application
* **CSS3** – Styling, layout, animations, and responsive design
* **JavaScript** – Application logic and interactivity
* **LocalStorage** – User session, cart, and order-history persistence
* **Web Speech API** – Voice payment notification
* **External Image URLs** – Product and background images

## 🚀 How to Run

### Option 1 – Open Directly

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html`.
4. The application will open in your web browser.

### Option 2 – Using VS Code

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Use **Live Server** to launch the application.

## 🌐 Language Support

The application supports three languages:

| Language | Support |
| -------- | ------- |
| English  | ✅       |
| Telugu   | ✅       |
| Hindi    | ✅       |

Users can change the language from the login screen, and the application updates the interface accordingly.

## 💳 Payment Methods

The checkout page provides the following payment options:

* PhonePe / UPI
* Debit Card
* Credit Card
* Cash on Delivery

The application demonstrates payment processing as a **frontend simulation**; it does not connect to a real payment gateway.

## 💾 Data Storage

The application uses the browser's **LocalStorage** to store:

* User login session
* Shopping cart
* Order history

This allows the application to retain user-related data in the same browser.

## 🔊 Voice Notification

After placing an order, the application can play a payment sound and use the browser's **Speech Synthesis API** to provide a voice notification in English, Telugu, or Hindi.

## 📸 Product Categories

The application includes:

* Ice Creams
* Fresh Juices
* Cakes
* Waffles
* Pancakes
* Brownies
* Milkshakes
* Desserts

Each category contains multiple flavours/products with different prices and images.
